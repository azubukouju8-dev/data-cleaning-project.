# Data Handling with Python — Reproducible Data Cleaning (B5)

A reproducible pandas workflow that cleans a messy **CSV, JSON and text** dataset into analysis-ready tables, with every decision documented.

> **Note:** the dataset is synthetic, generated by `generate_raw_data.py` with a fixed seed, so it is identical every time.

## Project structure
```
data-cleaning-project/
├── data/
│   ├── raw/                 # original data — never edited
│   │   ├── orders.csv       # 473 orders (CSV)
│   │   ├── products.json    # product catalogue (JSON)
│   │   └── reviews.txt      # customer reviews (text)
│   └── cleaned/             # created by the notebook
│       ├── orders_clean.csv
│       ├── products_clean.csv
│       └── reviews_clean.csv
├── notebooks/
│   └── data_cleaning.ipynb  # the full cleaning workflow
├── docs/
│   ├── data_dictionary.md          # every cleaned column explained
│   ├── data_profile.md             # before-and-after profile (generated)
│   ├── decision_log.md             # each decision, reason and trade-off
│   ├── transformation_log.md       # row counts per step (generated)
│   └── reproducibility_checklist.md
├── generate_raw_data.py     # recreates the raw data
├── requirements.txt
└── README.md
```

## How to run

**Option A — Google Colab (no install)**
1. Open `notebooks/data_cleaning.ipynb` in Colab (File → Upload notebook).
2. In the Files panel, create the folders `data/raw` and upload the three raw files into it.
3. Runtime → **Run all**. Cleaned files appear in `data/cleaned/`.

**Option B — Local**
```bash
python -m venv venv
venv\Scripts\activate          # Windows  (Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt
jupyter notebook               # open notebooks/data_cleaning.ipynb → Run All
```
Optional: regenerate the raw data with `python generate_raw_data.py`.

## Results

| | Raw | Clean |
|---|---|---|
| Orders | 473 rows, 23 country spellings, 6 date formats | 450 unique orders, 6 countries, one date format |
| Products | 13 rows, conflicting duplicate, mixed price types | 12 products, numeric prices |
| Reviews | 206 text lines incl. junk and duplicates | 180 structured reviews, ratings 1–5 |

Key cleaning steps: placeholder values → missing, duplicate removal, date parsing, category standardisation, numeric conversion, total recomputation, flagging impossible values instead of guessing, and parsing free-text reviews.

## Assumptions and limitations
- Ambiguous dates: `DD/MM/YYYY` when written with slashes, `MM-DD-YYYY` with dashes.
- Rows with impossible values are **flagged and kept**, not deleted.
- Full trade-offs: see [`docs/decision_log.md`](docs/decision_log.md).
